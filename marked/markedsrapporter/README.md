# Markedsrapporter

Ukentlig markedsoppdatering for Larsen Ski & Guiding. Ønsket tidspunkt: mandager kl. 09:00.

**MÅ AVKLARES:** Det er ikke bekreftet at noen automatisk rapport faktisk er satt opp og aktiv.

## Temaer
Ski- og fjellguiding i Norge, Hemsedal, Jotunheimen, etterspørsel, konkurrerende tilbud, nye kurs, sesongtrender, markedsmuligheter og Danmark som prioritert utenlandsmarked.

## Format (kort og konkret)
1. Viktigste nyheter
2. Kilder
3. Mulig betydning for bedriften
4. Inntil tre konkrete tiltak

Filnavn: `ÅÅÅÅ-MM-DD.md`
