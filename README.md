# Larsen Ski & Guiding

Prosjektmappe for Larsen Ski & Guiding. `CLAUDE.md` inneholder full prosjektkontekst og arbeidsprinsipper.

## Start her
- **`administrasjon/oppgaver.md`**: prioriterte oppgaver, åpne spørsmål og beslutningslogg

## Mapper
| Mappe | Innhold |
|---|---|
| `bedrift/` | Profil, kvalifikasjoner, strategi |
| `priser/` | Gjeldende priser (ingen godkjent ennå), historiske tilbud, prismodeller |
| `kurs/` | Skredkurs og skiteknikk |
| `hms/` | HMS-system (ikke ferdig og ikke godkjent) |
| `turer/` | Turplaner, pakkelister, kundeinformasjon |
| `kunder/` | Tilbud og oppfølging |
| `guider/` | Honorarmodell og oppgjør |
| `marked/` | Markedsrapporter, konkurrenter, samarbeidspartnere |
| `administrasjon/` | Booking, rutiner, oppgaver |
| `arkiv/` | Tidligere prosjekter og hendelser |

## Statusmerker
- **BEKREFTET**: tydelig etablert
- **HISTORISK**: tidligere priser, tilbud og oppdrag; ikke gjeldende
- **VURDERES**: ideer og forslag som ikke er vedtatt
- **MÅ AVKLARES**: ufullstendig eller motstridende
